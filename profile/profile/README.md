## 생각을 작동하는 도구로

이안 스튜디오는 일하는 방식을 먼저 이해하고, 필요한 만큼의 기술로 오래 쓸 수 있는 소프트웨어를 만듭니다.

### 01 · AI 문서 검색
내부 문서에서 필요한 정보를 찾고 질문에 답할 수 있는 검색 도구를 개발합니다.

### 02 · 업무 자동화
반복되는 문서 작성·정리·검토 업무를 자동화합니다.

### 03 · 웹·내부 도구 개발
고객의 웹 서비스와 팀의 업무 도구를 설계·개발하고 운영합니다.

---

## 우리가 일하는 방식

- **문제부터 확인합니다.** 요청의 배경과 실제 사용자를 이해한 다음 해결 범위를 정합니다.
- **작게 만들고 확인합니다.** 가장 중요한 기능부터 작동하는 결과로 검증합니다.
- **약속을 기록합니다.** 범위·일정·담당·완료 기준과 변경 영향을 남깁니다.
- **안전하게 운영합니다.** 고객 정보와 운영 데이터는 필요한 사람만 접근합니다.
- **AI 결과는 사람이 검토합니다.** 사실·권한·품질을 담당자가 확인합니다.
- **문서까지 전달합니다.** 코드와 함께 사용법·운영 방법·미완료 사항을 정리합니다.
